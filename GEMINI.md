# Cluvi AI

The `cluvi` MCP server (https://cluvi.ai/mcp) works on the person's own Cluvi AI workspace: their restaurant's guest conversations, delivery orders, menu, reservations, reports and the setup of the AI receptionist that answers their guests.

- If the server says it needs authentication, ask the person to run `/mcp auth cluvi` and sign in with their Cluvi AI account in the browser. There is no API key.
- One connection reaches one workspace, and the person's role decides which tools you see.
- The full connect guide for AI assistants: https://cluvi.ai/mcp.md
